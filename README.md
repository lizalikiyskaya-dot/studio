# Сайт «Лиза Андреенко — сопровождение автора»

Одностраничный лендинг студии художественной прозы: светлый градиент,
белые карточки, жёлтый акцент. Тексты собраны в `index.html` (октябрь 2026).
Форма анкеты по-прежнему уходит на `send.php`.

Тексты **не** берутся из `assets/content.json`. Деплой этот файл на сервере
не перезаписывает, поэтому старые правки админки не должны попадать на страницу.
`app.js` файл не читает. Мини-редактор с страницы снят: правка текста — в разметке.

## Структура
- `index.html` — разметка страницы
- `styles.css` — все стили; бренд-токены (цвета, шрифты) — в начале файла, блок `:root`
- `app.js` — анкета (`send.php`) и подсчёт «осталось N дн.» в окне кабинета.
  Контент страницы из `content.json` не подмешивается
- `assets/img/` — все фотографии
- `assets/posts.json` — лента статей (генерируется из Telegram, см. ниже)
- `privacy.html` — политика конфиденциальности
- `preview.html` / `preview.css` — **референс-макет, на сайте не используется** (не трогаем)

## Дизайн
- **Палитра** — «Солнечная»: жёлтый `#ffd43b`, фиолетовый `#6553e8`, чернила `#202020`.
  Токены в `:root` файла `styles.css`.
- **Шрифты** локально, `assets/fonts/`: Onest, Playfair Display, Literata, Marck Script.
- Первый экран — гибрид макетов 4б (от 761px) и 4 (телефон).

## Запуск локально
Нужен статический сервер (из-за путей и загрузки шрифтов):

    python3 -m http.server 8000
    # http://localhost:8000

## Где что менять
- **Тексты** — прямо в `index.html`. Страница не читает `content.json` и не берёт тексты из `app.js`.
- **Цвета и шрифты** — `styles.css`, блок `:root`, и файлы в `assets/fonts/`.
- **Фото Лизы** — `assets/img/hero_liza.jpg` и `hero_liza.webp`. Заглушки скриншотов, обложки и отзыва Анны — элементы с `data-placeholder` в `index.html`.
- **Анкета** — поля в `index.html`, проверка и письмо в `send.php`.
- **Пароль админки** — только переменная окружения `LIZA_ADMIN_PASSWORD` на сервере. В коде пароля нет. `save.php` на странице больше не вызывается.

## Блог: автосинк из Дзена
Скрипт `scripts/fetch-dzen.js` по-прежнему пишет `assets/posts.json` из канала
[dzen.ru/likiyawrites](https://dzen.ru/likiyawrites). Лендинг октября 2026 эту ленту
**не показывает**: на странице нет блока статей. Деплой живой `posts.json` не
перезаписывает, крон на сервере продолжает обновлять файл сам. Подпись автора
в скрипте — «Лиза Андреенко».

Обновить вручную:

    DZEN_CHANNEL=likiyawrites node scripts/fetch-dzen.js

В проде обновляется автоматически — GitHub Action `.github/workflows/sync-dzen.yml`
(крон раз в час). Число статей в ленте — переменная `DZEN_MAX`.

Публичный API Дзена отдаёт свежую статью. Скрипт дописывает её к уже
сохранённым в `posts.json`. На лендинг это не выводится.

## Форма заявки
Анкета в блоке `#apply` шлёт POST-JSON на **`send.php`**
(константа `LEAD_URL` в `app.js`). Обязательны имя и хотя бы один контакт:
Telegram или e-mail. Скрипт отсеивает ботов по honeypot-полю `_honey`,
ограничивает частоту (5 заявок с IP в час), дописывает лид
в `/var/lib/likiya/leads.jsonl` и отправляет письмо через `mail()` →
`/usr/sbin/sendmail` → **msmtp**. Адрес получателя задан в `send.php`
(`TO_EMAIL`), в клиентском коде его нет. Резервная копия заявки пишется
в localStorage браузера (`likiya:leads`). Старый набор полей формы
скрипт ещё принимает.
