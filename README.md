# Сайт «Лиза Ликийская — литературный наставник»

Одностраничный лендинг в редакторском стиле: минимализм, чёрно-белая
съёмка и золото как единственный акцент на белом фоне. Внутри —
лёгкая мини-админка, лента статей с автосинком из Telegram и форма заявки.

## Структура
- `index.html` — разметка страницы
- `styles.css` — все стили; бренд-токены (цвета, шрифты) — в начале файла, блок `:root`
- `app.js` — логика: контент по умолчанию (`DEFAULTS`), рендер ленты/отзывов,
  читалка статьи, форма заявки, режим правки, автосинк Telegram
- `assets/img/` — все фотографии
- `assets/posts.json` — лента статей (генерируется из Telegram, см. ниже)
- `privacy.html` — политика конфиденциальности
- `preview.html` / `preview.css` — **референс-макет, на сайте не используется** (не трогаем)

## Дизайн
- **Палитра** — золото `#b8944e` (акцент), белый фон, графит `#444444` (текст).
  Всё в CSS-переменных `:root` файла `styles.css` (`--burgundy` исторически = золото).
- **Шрифты** (Google Fonts, нужен интернет): Playfair Display — заголовки,
  Montserrat — основной текст и UI, Caveat — рукописный подзаголовок в героя.
- Первый экран — «карточка» с меню-топбаром, арочным коллажем фото и печатью;
  ниже — плавающая кнопка «Связаться», появляется при прокрутке.

## Запуск локально
Нужен статический сервер (из-за путей и загрузки шрифтов):

    python3 -m http.server 8000
    # http://localhost:8000

## Где что менять (без кода)
- **Цвета и шрифты бренда** — `styles.css`, блок `:root`.
- **Тексты/цены/контакты** — кнопка «✎ Редактировать» на сайте (пароль задаётся на сервере),
  правка прямо на странице → «Сохранить». Правки сохраняются в localStorage
  браузера (для правок с любого устройства нужна CMS — см. TODO).
- **Контент по умолчанию** — объект `DEFAULTS` в начале `app.js`.
- **Фото** — заменить файлы в `assets/img/` (имена те же) или пути в `DEFAULTS`.
- **Ссылка на Telegram** — `meta.telegram` в `DEFAULTS`.
- **Пароль админки** — переменная окружения `LIZA_ADMIN_PASSWORD` на сервере (см. DEPLOY.md, шаг 3); в коде его нет.

## Блог: автосинк из Дзена
Статьи тянутся из канала [dzen.ru/likiyawrites](https://dzen.ru/likiyawrites):
`scripts/fetch-dzen.js` берёт данные через публичный API Дзена
(`launcher/export`) и пишет `assets/posts.json`, который читает сайт.
На странице показывается **последняя** статья (обложка + заголовок + лид);
клик открывает читалку внутри сайта, полный текст — по кнопке «Открыть в Дзене».
Кнопка «Читать все статьи» разворачивает остальные, если они есть. Если
`posts.json` пуст/недоступен — показываются примеры из `DEFAULTS`.

Обновить вручную:

    DZEN_CHANNEL=likiyawrites node scripts/fetch-dzen.js

В проде обновляется автоматически — GitHub Action `.github/workflows/sync-dzen.yml`
(крон раз в час). Число статей в ленте — переменная `DZEN_MAX`.

> **Важно про Дзен.** Публичный API отдаёт только **свежую** статью (заголовок,
> лид, обложку, ссылку) — полный текст и архив закрыты логином Яндекса. Поэтому
> лента **накапливается**: каждый запуск добавляет новую статью к сохранённым,
> и со временем «Читать все статьи» наполняется. Полный текст в читалке возможен,
> только если у канала включён RSS-экспорт с полным содержимым — тогда скрипт
> можно перевести на этот RSS.

## Форма заявки
Форма (модалка + встроенная в секции «Контакты») шлёт POST-JSON на **`send.php`**
(константа `LEAD_URL` в начале `app.js`). Скрипт проверяет поля, отсеивает ботов
по honeypot-полю `_honey`, ограничивает частоту (5 заявок с IP в час), дублирует
лид в `/var/lib/likiya/leads.jsonl` и отправляет письмо через `mail()` →
`/usr/sbin/sendmail` → **msmtp** → SMTP-релей (настройки и пароль — в `/etc/msmtprc`
на сервере, в репозиторий не попадают). Адрес получателя задан в `send.php`
(`TO_EMAIL`), в клиентском коде его нет. Резервная копия заявки всегда пишется
в localStorage браузера (`likiya:leads`).

## Перед запуском в прод (нужны данные/действия владельца)
1. **Почта для заявок** — на сервере настроить `/etc/msmtprc` (SMTP-хост, ящик,
   пароль приложения) и проверить отправку: `echo test | sendmail -v адрес`.
2. **Домен в мета-тегах** — в `index.html` заменить `https://ЗАМЕНИТЕ-ДОМЕН/`
   в `og:url`, `og:image`, `twitter:image` на реальный абсолютный адрес.
3. **E-mail в политике** — в `privacy.html` (раздел 11) заменить `hello@example.com`.
4. **Автосинк блога (Дзен)** — запушить репозиторий на GitHub, включить в нём
   Actions → Workflow permissions → *Read and write*, задеплоить на хостинг
   с автодеплоем. (Опционально: включить RSS-экспорт канала в Дзене ради
   полного текста статей в читалке.)
5. **Ссылка на платформу для учеников** — кнопка на первом экране
   (`.start-platform` в `index.html`) пока без `href`; вписать, когда будет.
