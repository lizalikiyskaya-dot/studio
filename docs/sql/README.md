# Файлы схемы

Деплой сам применяет новые файлы из этого каталога. Отдельно заходить на сервер и запускать SQL не нужно.

Правила для нового файла:

- Только добавление: новая таблица, столбец, индекс, внешний ключ. Данные учеников не удалять и не переписывать.
- Повторный запуск ничего не ломает: `CREATE TABLE IF NOT EXISTS`, `ADD COLUMN IF NOT EXISTS`, `CREATE INDEX IF NOT EXISTS`.
- Имя лучше такое: `YYYY-MM-DD-короткое-описание.sql` (пример: `2026-10-18-book-plan-board.sql`). Файлы выполняются по алфавиту имени. Другое имя тоже примется, деплой из‑за него не остановится.
- Нельзя: `DROP TABLE`, `DROP COLUMN`, `TRUNCATE`, `DELETE`, `RENAME`. Такой файл деплой не применит и сайт на новый код не переключит.
- `DROP DEFAULT`, `DROP NOT NULL` и `ON DELETE CASCADE` можно: это не удаление строк.
- Уже применённый файл не менять. Следующая правка — новый файл.
- Свои `BEGIN` и `COMMIT` писать не обязательно: деплой и так выполняет файл одной транзакцией.

В `baseline.txt` только то, что уже было выполнено на проде до автоприменения. Новые файлы туда не вписывать.
